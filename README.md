# MOOGH — The AI Agent Desktop Workspace

MOOGH is a desktop AI Agent workspace for individuals and small teams. It brings chat, projects, files, code, tools, Skills, Plugins and MCP into one place, so an AI can keep working on a task instead of only answering questions.

## What it is

- Desktop AI agent workspace for Windows 10/11
- Project-level context: files, tasks and working state stay together across sessions
- Extensible: Skills, Plugins and MCP for task-specific capabilities
- Permission-based execution: review the plan before the agent acts

## What you can do with it

- Coding: read code, analyze logs, prepare fix proposals, build acceptance workflows
- Files & documents: draft, compare, summarize, organize on your local machine
- Automation: package repeatable workflows; small teams reduce repetitive work
- Research & reporting: turn files into structured deliverables in one workspace

## Quick start

1. Download for Windows from https://www.aimoogh.com/download/
2. Sign in and start - MOOGH is in open testing, with no subscription
3. Describe a real task in plain language
4. Review the agent plan and approve each step

## Pricing

MOOGH is in open testing. There is no subscription and no lock-in - you pay only for actual usage, with transparent top-ups (1 USD = 60 points) and no hidden fees.
