# What Is an AI Agent Desktop Client?

An AI agent desktop client is a native application that runs AI agents directly on your computer. Unlike a web chat, it can read and edit your local files, run commands in a terminal, and complete multi-step tasks on your behalf - with your permission at each step.

## Desktop client vs web chat

A web chat only talks. A desktop agent client acts: it can inspect your project, run commands, create files and verify results. That difference matters for real work - coding, file management, automation - where the AI needs access to your machine, not just a conversation window.

## How agents work on your PC

The client gives the model safe, permission-based tools: file read/write, terminal commands, task planning. Each action is proposed and executed transparently, and you can approve or reject it. Your data stays on your machine; only the task context is sent to the AI service.

## Why it matters

With a desktop agent, a task like "clean up this folder and generate a summary report" is something the AI can actually finish, not just explain. That is the difference between an assistant and a workbench.
