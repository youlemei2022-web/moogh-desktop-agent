# Why Project Context Matters More Than Chat History for AI Agents

Chat history records what was said; project context records what the work is - the files, code structure, prior decisions and the goal of the task. For complex, multi-step work, an agent that understands the project can continue where it left off instead of making the user re-explain everything.

## Chat history vs project context

A transcript helps the AI remember what was said. Project context tells it what the work actually is: which files are in scope, what has been tried, what the acceptance criteria are, and what was decided last week. For a one-off question you only need chat history. For a task that spans a project, you need both - and the project half is usually the part that is missing.

## Why it matters in practice

Real tasks span many steps and many files. Without project context, each session starts from zero: the same background, the same paths, the same constraints, explained again. That repeated setup is exactly the friction a desktop agent workspace removes.
