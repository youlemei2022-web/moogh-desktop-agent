# Is an AI Agent Safe to Run on My PC?

An AI agent is safe to run on your PC when it uses permission-based tools: every file change and command is proposed for your approval, execution is logged, and the agent only accesses the folders you scope it to.

## The safety features that matter

Look for four things before you install any agent client:

1. Explicit approval before any action runs
2. A visible log of everything the agent did
3. File access scoped to folders you specify
4. A clear data-handling policy about what is sent to the AI service

## How MOOGH approaches safety

MOOGH plans before it acts, shows you the proposed changes, executes only on approval, and keeps a full history of actions so nothing is invisible. The client is installed from the official site and does not run hidden background processes.

## Common-sense guardrails

Start with low-stakes tasks in a test folder, review the first few plans carefully, and keep the client updated. With approvals and logging in place, an agent is no riskier than giving a colleague limited access to your machine.
